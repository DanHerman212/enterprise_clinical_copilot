## Known debts, in the order they cost time

1. **Case data is baked into the harness image.** `suite2_cases.json` and `cases_82.json`
   live inside the container, so every test-data edit costs a build. This caused most of
   today's rebuild churn. Fix: mount or fetch them at run time.
2. **Failed gates do not clean up after themselves.** Scores and traces are written before
   the gate is evaluated, so a failed run leaves data behind. Design noted, not built.
3. **Image tags are nicknames** (`pilot2`), not commit SHAs, so an image cannot be mapped
   to a revision. `pipeline.yaml` already supports `--label=commit=${_TAG}`; the tag needs
   to be `$(git rev-parse --short HEAD)`.
4. **No build guard.** Nothing fails when the working tree is dirty, which is how images
   were built from uncommitted code all afternoon. A `git status --porcelain` check at the
   start of the pipeline closes it.
5. **Orphaned rows.** `observations` holds 1,860 rows belonging to traces deleted during
   the Langfuse cleanup; they do not render as traces but are dead weight.
6. **No push triggers.** Deploys are entirely manual, which is why "production" can diverge
   from `origin/main` without anything noticing.
